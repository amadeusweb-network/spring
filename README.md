* In Dec 2025, it was fronted by now [AW Oases](https://amadeusweb.in/log/2025/oases/#utm).

## Setup

1. Install Git, TortoiseGit, VS Code and Xampp (see "how to setup" link at step 3).
2. Create a folder -- `D:\Work\public_html`
3. visit [spring: start/how-to-setup](https://spring.amadeusweb.in/start/how-to-setup/) for the rest of the setup process
4. Go to: `D:\Work\public_html\spring\themes\canvas` and run `01--install-theme.bat`
5. visit [http://localhost/](http://localhost/) and you should see the **spring site** listed and when you click that, same as [spring.amadeusweb.in](https://spring.amadeusweb.in/).
